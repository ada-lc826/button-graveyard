# button-graveyard 宣传视频脚本（小红书 / 抖音）

**规格：** 1080×1920 竖屏 · 30 fps · 40.5 秒 · H.264 + AAC
**风格：** 冷幽默恐怖风。夜晚墓地配色：深蓝夜空、月亮、石碑；死亡用血红，复活用苔绿。
**原则：** 画面里的每个数字都来自对 `demo/broken` 和 `demo/fixed` 的真实扫描，没有一个是编的。
**安全区：** 重要文字都放在顶部到距底部约 400px 之间，并且离右边缘 150px 以外，避开抖音右侧的点赞/评论按钮和底部的标题文案。

## 发布小贴士

- **声音：** 视频自带合成配乐，所有音效都卡在点击和石碑落地上。抖音想蹭流量的话，可以在 App 里把原声音量调到约 30%，再叠一首热门 BGM。
- **配音：** 用手机按上表"配音"一栏照着时间点录一遍，导出 voice.wav，然后运行：
  ```bash
  ffmpeg -i button-graveyard-promo.mp4 -i voice.wav -filter_complex "[0:a]volume=0.4[m];[m][1:a]amix=inputs=2:duration=first[a]" -map 0:v -map "[a]" -c:v copy promo-voice.mp4
  ```
- **完播率：** 前 3 秒是钩子（"AI 四分钟"）。想更短的话，删掉第 7 段，能剪到约 36 秒。
- **发布时间：** 工作日 12:00–13:30 或 20:00–22:30。两个平台错开一小时发，方便分别回评论。
- **评论区：** 有人问"这不就是测试吗"，就回：它不写测试用例、不用配置、不靠 AI 判断，一条命令把整页按钮点一遍。
